# Noctra site — как устроен и как обновлять

## Где что лежит

- Исходники сайта: `C:\dev\riff\site`
- Собранный сайт для GitHub Pages: `C:\dev\riff\docs`
- Репозиторий: https://github.com/Sqwer2017/noctra (`main`)
- Публикация: GitHub Pages из ветки `main`, папка `/docs`
- Живой сайт: https://sqwer2017.github.io/noctra/

Сайт живёт в репозитории PC-версии Noctra. Android-приложение — отдельный репозиторий
`C:\dev\noctra-android`. Исходники PC-приложения и сайт не нужно смешивать.

## Стек

- Vite 7, React 19, `@react-three/fiber` и `@shadergradient/react` для живого фона
- Manrope для интерфейса, Cormorant Garamond для акцентного курсива
- Статическая сборка без сервера и базы данных
- Анимации интро, стекло, вкладки и тур сделаны на CSS и React, без внешних CDN

## Основные команды

```powershell
cd C:\dev\riff\site

npm install        # зависимости
npm run dev        # разработка на http://127.0.0.1:5180
npm run build      # сборка в C:\dev\riff\docs
npm run preview    # предпросмотр собранного сайта на http://127.0.0.1:5181
npm run assets     # пересобрать картинки из папки со скриншотами
```

`docs/` — результат сборки. Не редактируй его вручную: при следующем `npm run build`
Vite очистит папку и соберёт всё заново.

## Структура

```text
site/
  index.html                 — метатеги, OG, JSON-LD, точка входа
  vite.config.js             — сборка в ../docs, относительные пути
  scripts/prepare-assets.mjs — обработка логотипа, скриншотов и OG-карточки
  src/
    App.jsx                  — сценарии интро, знакомства, тура и настроек
    components/              — секции сайта и оверлеи
    data/content.js          — тексты, ссылки, платформы, FAQ, шаги тура
    lib/                     — устройство, релизы, счётчик, настройки, тултипы
    styles/                  — токены, секции, оверлеи, адаптив
    assets/media/            — обработанные скриншоты и логотипы
  public/                    — favicon, иконки, OG-картинка, .nojekyll
docs/                        — собранный статический сайт для Pages
```

## Что происходит при первом визите

1. Проигрывается интро: логотипы платформ сходятся к знаку Noctra.
2. Открывается знакомство: сопровождение по сайту, акцент и атмосфера.
3. После знакомства запускается тур (если выбран «Коротко» или «Подробно»).
4. Выбор сохраняется в `localStorage`; при следующем визите сайт открывается сразу.

Повторить заставку или тур можно в настройках (иконка ползунков в шапке) и в подвале.

## Персонализация

- `noctra:preferences` — акцент, атмосфера и режим сопровождения
- `noctra:intro-seen` — заставка уже показана
- `noctra:onboarded` — знакомство пройдено
- `noctra:downloads` — локальные нажатия на кнопки скачивания
- `noctra:latest-release` — кэш последнего релиза в `sessionStorage`

Акценты и атмосферы описаны в `site/src/lib/preferences.jsx`. Токены темы — в
`site/src/styles/base.css`.

## Скачивание и счётчик

- Кнопка определяет устройство по User-Agent: Windows, Android, iOS, macOS, Linux.
- Windows-установщик подтягивается из GitHub API последнего релиза; если API недоступен,
  открывается страница релизов.
- Android скачивает актуальный APK из релиза `android-latest`.
- iOS честно показывает, что сборки пока нет, и предлагает Android APK.
- Linux и macOS ведут на исходники и релизы.
- Счётчик скачиваний стартует с 13 и увеличивается при каждом нажатии на прямую ссылку.
  Данные пока демонстрационные; при появлении реального API достаточно заменить
  `simulatedDownloads` и `registerDownload` в `site/src/lib/downloads.jsx`.

Ссылки на релизы, APK и исходники лежат в `site/src/data/content.js`.

## Публикация

Перед публикацией проверь, что не уходят чужие изменения PC-приложения.
Не делай `git add .`. Добавляй только сайт:

```powershell
cd C:\dev\riff
git status
git add site docs SITE-GUIDE.md
git commit -m "Rebuild Noctra site"
git push origin main
```

Пуш выполнять только после разрешения владельца проекта. После пуша GitHub Pages
пересобирает сайт из `docs/` автоматически, обычно за 20–60 секунд.

Проверка деплоя:

```powershell
gh api repos/Sqwer2017/noctra/pages/builds/latest --jq "{status,commit}"
gh run list --repo Sqwer2017/noctra --limit 5
```

## Правила

- Не редактировать `docs/` вручную.
- Не пушить APK в Git, только в GitHub Releases.
- Не трогать `C:\dev\noctra-android` и PC-приложение, если задача про сайт.
- Перед пушем смотреть `git status`.
- Сайт статический: для работы достаточно `docs/` и любого статического сервера.
