# План: убрать плашку Supabase, усилить фон, починить анимации табов

## Что я замерил в браузере (оба бага подтверждены)

**1. Скачок высоты карточки — анимации нет вообще:**
```
cardIsMotion: false          ← карточка обычный <div>, не motion
projectionNodeCount: 0       ← Framer Motion её вообще не видит
```
Высота меняется мгновенно: `572px → 700px` одним кадром. `layout` не поможет, пока карточка не станет `motion.div`.

**2. Дёрганье плашки таба — координатное пространство:**
```
pill: position: absolute, x=784, parent = <button>
```
Плашка лежит `absolute` внутри `<button>`, а `layoutId` заставляет Framer Motion анимировать её между **двумя разными родителями**. Он измеряет позицию относительно каждого из них, и при переключении плашка сначала «прыгает» в новое пространство, потом доигрывает. Нужен `LayoutGroup` + вынос плашки из кнопок в общий контейнер, либо `layout`-совместимая структура.

## 2. Починка анимаций

**Плавный таб-переключатель** (по твоей схеме, но с исправлением координат):
- Активная плашка — **одна**, вне кнопок, в контейнере-родителе; кнопки идут поверх (`z-10`) и только меняют цвет текста.
- `layoutId="active-auth-pill"`, `spring { stiffness: 450, damping: 35 }`.
- Плашку вешаю на **conic/акцент** (`var(--accent)`) — как ты выбрал, чтобы она меняла цвет вместе с темой. Со свечением `shadow`.
- Оборачиваю в `LayoutGroup`, чтобы Framer Motion не путал пространства.

**Плавная высота карточки:**
- Карточка → `motion.div` с `layout` и `transition={{ layout: { duration: 0.35, ease: [0.16, 1, 0.3, 1] } }}`.
- Заголовок → `motion.div layout="position"` (текст меняется без скачка).
- Динамические поля (Никнейм, Повтори пароль) — `AnimatePresence initial={false}` + `height: 0 → auto`, с `overflow-hidden`. Сейчас там `mode="popLayout"`, что как раз и даёт рывок — заменю на обычный режим.
- Кнопка действия → `motion.div layout="position"`, чтобы съезжала вниз/вверх плавно.

## Риски

- `layout` на карточке может конфликтовать с `backdrop-blur` (эффект «матового стекла» иногда мерцает при анимации трансформации). Если увижу артефакты — вынесу blur на отдельный неподвижный слой под карточкой.
- Анимация высоты через `height: auto` требует `overflow-hidden` на обёртках полей, иначе контент «вылезает» в процессе — учту.
- Плашка на `var(--accent)`: при смене темы в настройках цвет меняется на лету, проверю, что свечение не отваливается.
- Клики в этой сессии харнесс иногда не прокидывает в кнопки — если не смогу прокликать, проверю через прямые замеры DOM/CSS и явно об этом скажу.
