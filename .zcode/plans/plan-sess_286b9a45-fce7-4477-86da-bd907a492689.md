### 1. Миграции (нужно выполнить)

```sql
  ADD COLUMN IF NOT EXISTS daily_tracks   JSONB NOT NULL DEFAULT '{}'::jsonb,
  ADD COLUMN IF NOT EXISTS daily_favorites JSONB NOT NULL DEFAULT '{}'::jsonb;
```

Формат — как у `listening_history`: `{"2026-09-16": 12}`.

**Порядок применения:** `006` → `007` → `009` → `010`.

### 2. Счётчики достижений (клиент + база)

Добавлю в `useProgressionStore` накопительные счётчики и научу клиент их отправлять:

- **`night_plays`** — в `registerTrackCompleted` проверяем локальный час: 0–5 → инкремент. Считает треки, дослушанные ночью.
- **`max_session_seconds`** — в `tickListening` ведём `currentSessionSeconds` (растёт на каждом тике, сбрасывается при паузе дольше 5 минут) и пишем `max(currentSession, maxSessionSeconds)`. Даёт «Шёпот пустоты» (1 час).
- **`repeat_loops`** — в `handleTrackEnded` при `repeat-one` инкрементим счётчик **подряд идущих** повторов одного трека; сбрасывается при смене трека.
- **`shuffle_streak`** — считаем подряд идущие треки, проигранные в режиме `shuffle`, с разными id; сбрасывается при выходе из режима.
- **`source_kinds`** — множество уникальных `source` среди прослушанных треков (`SoundCloud`/`Audius`/`Telegram`/`Telegram Test`), хранится как битовая маска или список.

Всё это уходит в `user_stats` вместе с существующими полями. Защита от абуза: счётчики **накопительные** (`max`, а не `+1`), поэтому перезагрузка их не сбросит и не задвоит.

### 3. Прогресс-бары достижений

Расширю `AchievementMetrics` и `getMetricValue`, чтобы обрабатывались все 14 метрик. Значения `night_plays`, `session_seconds`, `repeat_loops`, `shuffle_streak`, `dual_source` будут приходить из стора (данные, которые мы теперь считаем). Для `album_complete` и `profile_complete` (событийные, `target: null`) полоса не рисуется — как и сейчас.

### 4. История по дням и неделям

- **Треки** (`daily_tracks`) и **лайки** (`daily_favorites`) — инкремент по дате, как у `historyMap`.
- **Дни активности** — по твоему выбору считаем **уникальные дни за неделю**: `3 из 7`. Дельта — сравнение текущей недели с прошлой.
- Добавлю `computeDailyDelta` / `computeWeeklyDelta` рядом с существующим `computeTodayDelta`, обобщив текущую логику.
- Всё сохраняется в БД per-user и мержится при гидратации (как `mergeHistory`).

Оптимистично обновляем UI, в облако уходит через существующий троттлинг.

### 5. Анимация обложки

Возвращаю оверлей: затемнение картинки + иконка `Maximize2` в центре, через состояние (`onPointerEnter/Leave`), а не CSS-hover — иначе конфликт с `whileHover` от Framer Motion. Плюс усиливаю масштаб и добавляю свечение по акцентному цвету.
